## 📖 نبذة عن المشروع (Overview)

**بورتفوليو Hub** هو نظام SaaS متكامل يتيح للمهنيين، المستقلين، والشركات من مختلف التخصصات (مطورين، أطباء، مهندسين، محامين، معلمين، تنفيذيين، وغيرهم) إنشاء مواقع بورتفوليو شخصية احترافية بدون كتابة سطر كود واحد، مع رابط مخصص لكل عميل (Slug)، ولوحة تحكم شاملة لإدارة المحتوى، ونظام مراجعة وتدقيق إداري قبل النشر، مع إمكانية تصدير الموقع بالكامل كملف `ZIP` ثابت (Static HTML/CSS) للاستضافة المستقلة.

## 🎯 المشكلة التي يعالجها المشروع (The Problem)

يعاني غالبية أصحاب المهن والمستقلين عند رغبتهم في عرض أعمالهم من عقبات رئيسية:

1. **التكلفة العالية والتعقيد التقني:** يتطلب بناء موقع شخصي توظيف مطورين أو استخدام منصات معقدة تتطلب خبرة برمجية ورسوم اشتراك مرتفعة.
2. **ضعف دعم اللغة العربية والـ RTL:** معظم المنصات العالمية لا تدعم اللغة العربية بطريقة سليمة، مما يؤدي إلى تشوه الخطوط والاتجاهات (RTL/LTR) وصعوبة توفير نسخة ثنائية اللغة لنفس المحتوى.
3. **عدم ملاءمة القالب للمهنة:** القوالب التقليدية غالباً ما تُصمم للمبرمجين أو المصممين فقط (مثل أشرطة النسب المئوية للمهارات وربط حسابات GitHub)، وهي غير ملائمة نهائياً لطبيب أو محامٍ أو مدير تنفيذي.
4. **بطء الأداء وثقل أنظمة إدارة المحتوى التقليدية:** منصات مثل WordPress تعاني من استهلاك كبير لموارد الخادم، والبطء في تحميل الصفحات، وثغرات الإضافات المستمرة.
5. **الارتهان للمنصة (Vendor Lock-in):** لا تمنح معظم منصات إنشاء المواقع للمستخدم الحق في سحب أكواد موقعه وبياناته واستضافتها على سيرفره الخاص أو نطاقه المستقل.

## 💡 الحل والقيمة المضافة (The Solution & Value Proposition)

يقدم هذا المشروع حلاً جذرياً من خلال:

* **إطلاق فوري للموقع:** إنشاء وتفعيل الموقع الشخصي خلال دقائق معدودة مع لوحة تحكم تفاعلية مقسمة لتبويبات سهلة الاستخدام.
* **نظام التكيف المهني الفريد (Profession-Adaptive Engine):** يضبط تلقائياً مسميات الأقسام، والأيقونات، ولوحات الألوان، وسلوك العرض (إخفاء أو إظهار أشرطة المهارات) بما يتناسب بدقة مع مهنة صاحب الموقع.
* **ثنائية اللغة الحقيقية (AR / EN):** إدارة محتوى الموقع باللغتين العربية والإنجليزية بالتوازي مع دعم كامل لاتجاه الصفحة والتصميم المتناسق.
* **أداء خارق عبر التخزين المؤقت (High-Performance Caching Layer):** توليد صفحات HTML ساكنة لكل مستأجر، مما يجعل زمن الاستجابة أجزاءً من الثانية بدون أي ضغط على قاعدة البيانات.
* **حرية التصدير (Static ZIP Export):** إمكانية تحميل الموقع بالكامل بضغطة زر كأكواد HTML/CSS/JS وصور مضغوطة لنشرها على GitHub Pages أو Netlify أو أي استضافة خاصة.
* **الأمان والعزل الكامل للمستأجرين:** عزل منطقي متين للبيانات يمنع وصول أي مستخدم لبيانات مستخدم آخر.

## ✨ المميزات الرئيسية (Key Features)

### 👤 1. ميزات العميل / صاحب الموقع (Client Features)
* **لوحة تحكم عصرية:** إدارة شاملة للمعلومات الشخصية، روابط التواصل، المهارات، الخبرات، المؤهلات العلمية، الشهادات، المشاريع، واللغات.
* **إدارة المشاريع الموسعة:** إمكانية رفع أغلفة المشاريع، ومعرض وسائط لكل مشروع (صور متعددة، مستندات PDF)، وتحديد روابط العرض وGitHub.
* **صفحات تفصيلية للمشاريع:** إنشاء رابط مستقل لكل مشروع (`/{slug}/projects/{project_slug}`) بمحتوى متكامل ومعرض شرائح.
* **تغيير القالب والمهنة:** حرية التبديل بين القوالب والألوان المهنية بنقرة واحدة مع إعادة هيكلة الأقسام تلقائياً.
* **الضغط التلقائي للصور (WebP & JPEG):** نظام آلي يقوم بضغط الصور وتحجيمها لتقليل استهلاك المساحة وتسريع التحميل مع توفير بديل آمن في حال غياب مكتبة GD.
* **محدد لغة افتراضية:** إمكانية جعل الموقع أحادي اللغة (عربي أو إنجليزي فقط) أو تفعيل الوضع ثنائي اللغة بنقرة واحدة.
* **نظام إرسال للمراجعة (Approval Workflow):** إشعار الإدارة بجاهزية الموقع للنشر وتلقي الملاحظات في حال الرفض.
* **تصدير الموقع ZIP:** تنزيل حزمة الموقع الكاملة جاهزة للعمل دون اتصال بالإنترنت أو قاعدة بيانات.

### 🛡️ 2. ميزات لوحة الإدارة (Admin Features)
* **إدارة المستأجرين والمواقع:** استعراض جميع المستخدمين والمواقع، ومتابعة حالات التفعيل، والقوالب المستخدمة.
* **نظام الموافقة والرفض:** مراجعة محتوى أي موقع قبل نشره للعامة مع إمكانية الرفض مع ذكر الأسباب الموضحة للعميل.
* **انتحال صفحة العميل (Tenant Impersonation):** تسجيل الدخول كأي مستأجر مباشرة لتقديم الدعم الفني وتعديل المحتوى ثم العودة لحساب الإدارة بنقرة واحدة.
* **تعديل القوالب والمهن للمستخدمين:** قدرة المدير على إعادة تخصيص قالب أو مهنة معينة لأي عميل.
* **إنشاء حسابات عملاء:** إضافة عملاء جدد وتعيين روابطهم وقوالبهم يدوياً من لوحة الإدارة.
* **إيقاف/تفعيل الحسابات:** التحكم الفوري في تجميد أو إعادة تنشيط أي حساب مستأجر مع مسح الكاش فوراً.

### 🌐 3. ميزات زوار الموقع ومحركات البحث (SEO & Visitor Experience)
* **دعم الوضعين المظلم والفاتح (Dark & Light Mode):** تبديل سلس وجميل للثيم مع حفظ تفضيل الزائر.
* **مُبدل اللغة اللحظي:** انتقال فوري بين العربية (RTL) والإنجليزية (LTR).
* **تهيئة متكاملة لمحركات البحث (SEO & Social Sharing):**
  * وسوم Open Graph لمشاركة الروابط على فيسبوك وتويتر مع توليد الصورة والوصف تلقائياً.
  * بيانات وصفية منظمة بتنسيق **JSON-LD Schema** (نوع الشخص Person).
  * وسوم Canonical لتفادي تكرار المحتوى.
* **تتبع وتحليلات متقدمة (Google Analytics 4):** دمج جاهز لـ GA4 مع تعقب مخصص للنقرات والاتصالات وتحميل السير الذاتية وطلبات واتساب.
* **بانر خدمة السيرة الذاتية الاحترافية (ATS CV):** نافذة دعائية متناسقة لطلب خدمة كتابة السيرة الذاتية المهنية.

## 🏗️ البنية التقنية والمعمارية (Architecture)

تم بناء النظام وفق معمارية **MVC (Model-View-Controller)** أصيلة وخفيفة بدون الاعتماد على أطر عمل خارجية ثقيلة، لضمان السرعة القصوى وسهولة الصيانة:

```
SaaS_Multi_Tenant_platform/
├── app/
│   ├── Config/              # ملفات التهيئة (المهن والتخصيصات)
│   ├── Controllers/         # وحدات التحكم (Admin, Client, Auth, Site)
│   ├── Core/                # النواة الأساسية (Database, Router, BaseModel, Auth)
│   ├── Middleware/          # طبقات الحماية (Auth, Role, SiteOwnership)
│   ├── Models/              # نماذج البيانات (User, Site, Profile, Project...)
│   ├── Services/            # خدمات المعالجة (Compression, Export, Approval, Upload)
│   └── Views/               # قوالب العرض (Admin, Client, Auth, Public)
├── cache/                   # مجلد التخزين المؤقت للمواقع المنشورة (.html)
├── exports/                 # ملفات المواقع المصدرة مؤقتاً
├── public/                  # المجلد الجذري للخادم (Front Controller & Assets)
│   ├── assets/              # ملفات الـ CSS والـ JS العامة
│   ├── uploads/             # مجلد وسائط المستأجرين المعزول
│   ├── index.php            # موجه الطلبات الأساسي (Router Dispatcher)
│   └── .htaccess            # إعادة توجيه الروابط وتنسيق Clean URLs
├── templates/               # القوالب القابلة للتطبيق (Developer, Doctor, Company)
├── schema.sql               # بنية قاعدة البيانات الكاملة مع البيانات الأولية
└── index.php                # إعادة التوجيه إلى public/
```

## 🔒 الأمان وحماية البيانات (Security Measures)

* **عزل البيانات بين المستأجرين (Tenant Data Isolation):** يضمن `SiteOwnershipMiddleware` أن كل عملية حفظ أو تعديل أو رفع ملفات محصورة برقم الموقع المنسوب لحساب المستخدم الحالي فقط.
* **حماية من هجمات CSRF:** توليد وتدقيق توكنات الـ CSRF في جميع نماذج الإرسال وروابط العمليات الإدارية الحساسة.
* **التحصين ضد SQL Injection:** الاعتماد الكامل على استعلامات `PDO Prepared Statements` مع حظر `Emulate Prepares`.
* **الحماية من هجمات XSS:** تعقيم وتطهير كل المخرجات والمدخلات باستخدام `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`.
* **تشفير كلمات المرور:** استخدام خوارزمية `BCRYPT` الحديثة لتشفير كلمات المرور.
* **استعادة آمنة للحسابات:** آلية للتحقق من هوية المستخدم المنسية عبر البريد ورقم الهاتف المسجل قبل فتح نموذج تعيين كلمة مرور جديدة.

## ⚙️ التقنيات المستخدمة (Tech Stack)

* **لغة البرمجة الأساسية:** PHP 8.1+ (Object-Oriented Programming, Clean Code).
* **قاعدة البيانات:** MySQL / MariaDB (InnoDB, UTF8mb4).
* **الواجهات والتصميم:** HTML5 دلالي، CSS3 مرن (Custom Properties & Flex/Grid)، JavaScript نقي (Vanilla JS).
* **الأيقونات والخطوط:** FontAwesome 6 Pro/Free، خطوط Google المتناسقة مع العربية والإنجليزية (Cairo, Inter).
* **التخزين ومعالجة الوسائط:** مكتبة PHP GD مع ضغط WebP وJPEG.
* **الخادم والأرشفة:** Apache مع تفعيل `mod_rewrite` ومكتبة `ZipArchive`.
* **التحليلات:** Google Analytics 4 (GA4).

## 🚀 دليل التثبيت والتشغيل (Installation Guide)

### 1. المتطلبات المسبقة (Prerequisites)
* حزمة خادم محلي مثل **XAMPP** أو **WAMP** أو **Laragon** (تعمل مع PHP 8.0 أو أحدث).
* قاعدة بيانات **MySQL 5.7+** أو **MariaDB**.
* تفعيل امتدادات PHP التالية في ملف `php.ini`:
  * `pdo_mysql`
  * `gd` (لمعالجة وضغط الصور)
  * `zip` (لتصدير حزم الـ ZIP)
  * `mbstring`

### 2. خطوات التثبيت (Step-by-Step Setup)

#### الخطوة 1: استنساخ المشروع
ضع مجلد المشروع داخل مجلد الويب الخاص بخادمك (مثلاً: `C:\xampp\htdocs\SaaS_Multi_Tenant_platform`).

#### الخطوة 2: إنشاء قاعدة البيانات واستيراد المخطط
1. افتح **phpMyAdmin** أو أداة إدارة MySQL لديك.
2. أنشئ قاعدة بيانات جديدة باسم:
   ```sql
   CREATE DATABASE saas_portfolios CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
3. قم باستيراد ملف [`schema.sql`](file:///c:/xampp/htdocs/SaaS_Multi_Tenant_platform/schema.sql) المرفق في جذر المشروع داخل قاعدة البيانات.

#### الخطوة 3: ضبط إعدادات الاتصال بقاعدة البيانات
تحقق من إعدادات الاتصال داخل ملف [`app/Core/Database.php`](file:///c:/xampp/htdocs/SaaS_Multi_Tenant_platform/app/Core/Database.php):
```php
private string $host     = '127.0.0.1';
private string $dbname   = 'saas_portfolios';
private string $username = 'root';
private string $password = '';
```

#### الخطوة 4: تشغيل الموقع
افتح المتصفح وانتقل إلى الرابط المحلي:
```
http://localhost/SaaS_Multi_Tenant_platform/
```
سيقوم النظام تلقائياً بتحويلك إلى الصفحة الرئيسية الجذابة (`public/`).

## 🧭 كيفية الاستخدام (Usage Guide)

1. **تسجيل الحساب:** يدخل المستخدم إلى صفحة التسجيل ويحدد البريد الإلكتروني، رقم الهاتف، كلمة المرور، واسم الرابط (Slug) المطلوب لموقعه (مثل `ali-ahmed`).
2. **تجهيز المحتوى:** ينتقل العميل إلى لوحة التحكم `/dashboard`، ويقوم بتعبئة بياناته باللغتين العربية والإنجليزية ورفع صورته وسيرته الذاتية.
3. **اختيار القالب والمهنة:** من تبويب الإعدادات، يختار المهنة المناسبة (طبيب، مهندس، مبرمج...) ليتم تطبيق الألوان والتسميات فوراً.
4. **إرسال الموقع للمراجعة:** يضغط العميل على زر **"إرسال للمراجعة"**.
5. **الموافقة والنشر:** يدخل مدير النظام للوحة الإدارة `/admin` ويعاين الموقع ثم ينقر **"موافقة"**، ليصبح الموقع متاحاً للجمهور فوراً على الرابط:
   ```
   http://localhost/SaaS_Multi_Tenant_platform/{slug}
   ```
6. **تصدير الموقع:** يستطيع العميل في أي وقت النقر على **"تصدير الموقع كملف ZIP"** والحصول على نسخة ثابتة لموقعه.
